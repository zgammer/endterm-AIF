# Книга волшебных алгоритмов (проект «книга для AIF»)

Интерактивная электронная книга по лекциям курса **AI Fundamentals**, оформленная как сказочная книга из начала фильмов «Шрек»: пергамент, буквицы, геральдические бордюры, закрытая книга на столе, которая открывается при прокрутке.

Формат: веб-страница на обычном HTML, CSS и JS, без фреймворков. Текущая версия: **v0.3, главы I–II** (страницы листаются при прокрутке, текст на английском, выбор шрифта).

---

## 1. Требования

1. Стиль: сказочная книга из начала «Шрека».
2. Формат: веб-страница (или сборник страниц), без фреймворков.
3. Интерактивы: мини-тесты по темам и спрятанные предметы на страницах.
4. Финальная кнопка внизу страницы открывается, если выполнено **одно из двух условий**: все ответы на вопросы верны **или** найдены все спрятанные предметы.
5. По нажатию кнопки: имитация загрузки, затем показ картинки-награды (`img/reward.jpg`, Осёл с цитатой).

### Принятые решения

- При открытии страницы книга **лежит закрытой на столе**. Книга остаётся на экране, а при прокрутке вниз сначала откидывается обложка, затем **страницы листаются одна за другой** так же, как открывается обложка. Главы не лежат ниже книги: они и есть страницы книги. Последняя страница — печать с счётчиками и кнопкой.
- Книга крупная: на ПК разворот занимает почти весь экран (масштаб подбирается под размер окна). На узких экранах (до 820 px) показывается по одной странице.
- Спрятанных предметов **по 3 на каждую главу** (не 12 на всю книгу). Предмет: знак «Beware Ogre» (`img/hidden-object.png`).
- Счётчик «Знаки X/N · Ответы Y/M» стоит **над финальной кнопкой**; значения N и M считаются по странице автоматически.
- **Язык книги:** английский (интерфейс, тексты глав, вопросы). README и комментарии в коде на русском.
- **Шрифт:** кнопка «Aa» в правом верхнем углу переключает шрифт (Classic storybook / mr_AprilraG / Plain serif), выбор запоминается.
- Иллюстрации рисует команда по промптам из `docs/image-prompts.md`. Пока файлов нет, на их месте рамка с именем нужного файла.

## 3. Дизайн

- **Палитра:** пергамент (кремовый), тёмно-синий `#243a7a`, кирпично-красный `#a62d1f`, зелёный `#2f6b3a`, золото `#c9a13b`.
- **Шрифты (Google Fonts, нужен интернет):** *Uncial Antiqua* для заголовков, *IM Fell English* для текста.
- **Элементы:** буквица, геральдические полосы (`.band`), рамки-блоки с формулами, код в тёмных «свитках», иллюстрации с подписями.
- **Иллюстрации:** оригинальные, в стиле средневековых рукописей. Кадры и персонажей фильма напрямую не используем (авторские права).

## 4. Структура проекта

```
index.html          собранная страница (генерируется build.py, можно открывать двойным кликом)
build.py            сборка index.html из partials/ и chapters/
css/book.css        все стили
js/book.js          прогресс, тесты, предметы, финал, листание страниц при прокрутке
partials/header.html  шапка, закрытая книга (hero) и контейнер страниц #src
partials/footer.html  последняя страница (печать, счётчики, кнопка), оверлей награды, подключение скрипта
chapters/ch1.html …   по одному файлу на главу: набор страниц <article class="pg">
img/                иллюстрации, предмет и награда
fonts/              свои шрифты (mr_AprilraG.ttf / .otf / .woff2)
docs/image-prompts.md промпты и имена файлов для всех картинок
```

## 5. Как работать

**Сборка:** после правок в `chapters/` или `partials/` запустите `python3 build.py`. Он пересоберёт `index.html`. Правки в `css/` и `js/` сборки не требуют.

**Запуск:** откройте `index.html` в браузере. Для публикации подойдёт GitHub Pages или Netlify (загрузить всю папку).

**Новая глава:** создайте `chapters/chN.html` (N — следующий номер). Глава состоит из **страниц**: каждая страница это `<article class="pg">…</article>`. Книга сама собирает страницы в листы: разворот = две страницы подряд. Одна страница вмещает примерно: заголовок + абзац + иллюстрацию, или таблицу + иллюстрацию, или 3 вопроса. Если контента больше, внутри страницы появится прокрутка, поэтому лучше разбивать на несколько страниц.

```html
<article class="pg">
  <h2><small>Глава III</small>Название</h2>
  <p class="drop">Текст с буквицей…</p>
  <figure class="ill" data-f="img/ch3-01-name.png"><img src="img/ch3-01-name.png" alt="…" onerror="this.parentNode.classList.add('miss')"><figcaption>Подпись</figcaption></figure>
</article>
<article class="pg">
  <h2><small>Глава III</small>Испытание знанием</h2>
  <div class="q" data-a="1"><p>1. Вопрос?</p>
    <button>Вариант 0</button><button>Вариант 1</button><button>Вариант 2</button>
    <div class="no">Подсказка при ошибке.</div><div class="ex">Объяснение верного ответа.</div></div>
  <i class="h" style="transform:rotate(-12deg)" data-n="Берегись огра"></i>
</article>
```

- `data-a` — номер верного варианта (с нуля).
- **В каждой главе ровно 3 элемента `.h`** (предмета), раскиньте их по разным страницам главы. Для абсолютной позиции добавьте класс `a` и `style="right:8px;bottom:30%"`.
- Вопросов рекомендуем 3–5 на главу.
- Порядок страниц в книге: главы по номеру, затем последняя страница с печатью. Если страниц получается чётное число, книга сама добавит пустую.
- Счётчики и условие разблокировки подхватят новую главу автоматически.

## 6. Как работают интерактивы

- Прогресс (найденные предметы и верные ответы) хранится в `localStorage` под ключом `aif-book-v2`.
- Сброс прогресса: в консоли браузера `localStorage.removeItem("aif-book-v2")`.
- Неверный ответ можно исправить, верный фиксируется с объяснением.
- Печать/кнопка активируется при `предметы == все` **или** `ответы == все`. Нажатие запускает полосу загрузки (≈8 сек) и показывает `img/reward.jpg`.
- Проверка идёт в браузере, поэтому её технически можно обойти. Для учебной книги это допустимо.

## 6a. Шрифты

Кнопка «Aa» меняет шрифт всей книги. Шрифт **mr_AprilraG** файл не входит в проект: положите его в папку `fonts/` под одним из имён `mr_AprilraG.ttf`, `mr_AprilraG.otf` или `mr_AprilraG.woff2` (остальные подключения уже прописаны в `css/book.css`). Пока файла нет, пункт mr_AprilraG показывает запасной шрифт. Проверьте лицензию шрифта, если книга будет публичной. Чтобы добавить ещё один шрифт, добавьте `@font-face` и правило `html[data-font="имя"]` в `css/book.css`, а кнопку с `data-f="имя"` в `partials/header.html`.

## 7. Иллюстрации

Полный список файлов, размеров и промптов: `docs/image-prompts.md`. Кратко:

- общие: `cover.png`, `endpaper.png`, `parchment.jpg`, `table-wood.jpg`;
- глава I: `ch1-01-quest.png`, `ch1-02-fringe.png`, `ch1-03-astar.png`;
- глава II: `ch2-01-landscape.png`, `ch2-02-restarts.png`, `ch2-03-annealing.png`;
- главы III–VII: `ch3-probability.png`, `ch4-hmm.png`, `ch5-decisions.png`, `ch6-clusters.png`, `ch7-rl.png`.

Рекомендуемый формат иллюстраций — 3:2 (1200×800). Картинки другого формата (например 4:3) не ломают страницу: они обрезаются до рамки одинаковой высоты (`object-fit: cover`), поэтому важное держите ближе к центру. Положите файлы в `img/` с этими именами, и они подхватятся без правок кода (фоны `cover`, `endpaper`, `parchment`, `table-wood` тоже подключены в CSS).

## 9. Ограничения и идеи

- Шрифты подгружаются с Google Fonts. Для работы без интернета скачайте их в `fonts/`.
- Идеи: формулы через KaTeX, звук перелистывания, карта прогресса по главам, кнопки «следующая/предыдущая страница».
- Листание привязано к положению прокрутки. Если страница с внутренней прокруткой (много контента), колесо мыши сначала прокручивает её, а потом листает книгу.
