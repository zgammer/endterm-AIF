# Книга волшебных алгоритмов (проект «книга для AIF»)

Интерактивная электронная книга по лекциям курса **AI Fundamentals**, оформленная как сказочная книга из начала фильмов «Шрек»: пергамент, буквицы, геральдические бордюры, закрытая книга на столе, которая открывается при прокрутке.

Формат: веб-страница на обычном HTML, CSS и JS, без фреймворков. Текущая версия: **v0.1, главы I–II**.

---

## 1. Требования

1. Стиль: сказочная книга из начала «Шрека».
2. Формат: веб-страница (или сборник страниц), без фреймворков.
3. Интерактивы: мини-тесты по темам и спрятанные предметы на страницах.
4. Финальная кнопка внизу страницы открывается, если выполнено **одно из двух условий**: все ответы на вопросы верны **или** найдены все спрятанные предметы.
5. По нажатию кнопки: имитация загрузки, затем показ картинки-награды (`img/reward.jpg`, Осёл с цитатой).

### Принятые решения

- При открытии страницы книга **лежит закрытой на столе**, при прокрутке вниз обложка откидывается, затем главы разворачиваются по мере появления на экране.
- Спрятанных предметов **по 3 на каждую главу** (не 12 на всю книгу). Предмет: знак «Beware Ogre» (`img/hidden-object.png`).
- Счётчик «Знаки X/N · Ответы Y/M» стоит **над финальной кнопкой**; значения N и M считаются по странице автоматически.
- Иллюстрации рисует команда по промптам из `docs/image-prompts.md`. Пока файлов нет, на их месте рамка с именем нужного файла.

## 3. Дизайн

- **Палитра:** пергамент (кремовый), тёмно-синий `#243a7a`, кирпично-красный `#a62d1f`, зелёный `#2f6b3a`, золото `#c9a13b`.
- **Шрифты (Google Fonts, нужен интернет):** *Uncial Antiqua* для заголовков, *IM Fell English* для текста.
- **Элементы:** буквица, геральдические полосы (`.band`), рамки-блоки с формулами, код в тёмных «свитках», иллюстрации с подписями.
- **Иллюстрации:** оригинальные, в стиле средневековых рукописей. Кадры и персонажей фильма напрямую не используем (авторские права).

## 4. Структура проекта

```
index.html          собранная страница (генерируется build.py, можно открывать двойным кликом)
build.py            сборка index.html из partials/ и chapters/
css/book.css        все стили
js/book.js          прогресс, тесты, предметы, финал, открытие книги
partials/header.html  шапка, закрытая книга (hero), начало <main>
partials/footer.html  заключение, печать, счётчики, кнопка, оверлей награды, подключение скрипта
chapters/ch1.html …   по одному файлу на главу (блок <section id="cN">)
img/                иллюстрации, предмет и награда
docs/image-prompts.md промпты и имена файлов для всех картинок
```

## 5. Как работать

**Сборка:** после правок в `chapters/` или `partials/` запустите `python3 build.py`. Он пересоберёт `index.html`. Правки в `css/` и `js/` сборки не требуют.

**Запуск:** откройте `index.html` в браузере. Для публикации подойдёт GitHub Pages или Netlify (загрузить всю папку).

**Новая глава:** создайте `chapters/chN.html` (N — следующий номер) по образцу ch1.html:

```html
<section id="c3">
  <h2><small>Глава III</small>Название</h2>
  <p class="drop">Текст с буквицей…</p>
  <figure class="ill" data-f="img/ch3-01-name.png"><img src="img/ch3-01-name.png" alt="…" onerror="this.parentNode.classList.add('miss')"><figcaption>Подпись</figcaption></figure>
  <div class="q" data-a="1"><p>1. Вопрос?</p>
    <button>Вариант 0</button><button>Вариант 1</button><button>Вариант 2</button>
    <div class="no">Подсказка при ошибке.</div><div class="ex">Объяснение верного ответа.</div></div>
  <i class="h" style="transform:rotate(-12deg)" data-n="Берегись огра"></i>
</section>
```

- `data-a` — номер верного варианта (с нуля).
- **В каждой главе ровно 3 элемента `.h`** (предмета). Прячьте их в тексте, таблицах, у краёв. Для абсолютной позиции добавьте класс `a` и `style="right:8px;bottom:30%"`.
- Вопросов рекомендуем 3–5 на главу.
- Счётчики и условие разблокировки подхватят новую главу автоматически.

## 6. Как работают интерактивы

- Прогресс (найденные предметы и верные ответы) хранится в `localStorage` под ключом `aif-book-v2`.
- Сброс прогресса: в консоли браузера `localStorage.removeItem("aif-book-v2")`.
- Неверный ответ можно исправить, верный фиксируется с объяснением.
- Печать/кнопка активируется при `предметы == все` **или** `ответы == все`. Нажатие запускает полосу загрузки (≈8 сек) и показывает `img/reward.jpg`.
- Проверка идёт в браузере, поэтому её технически можно обойти. Для учебной книги это допустимо.
